## 4. Technical Explanations & Algorithmic Foundations
### 1. The Paradigm of AI-Assisted Programming
AI coding tools are not autonomous software engineers; they are probabilistic autocomplete engines on steroids.
* **The Augmented Developer:** An expert coder using AI can write boilerplate, unit tests, and regex expressions 3x to 5x faster.
* **The 'Vibe Coder' Trap:** A beginner who blind-copies AI code without understanding line-by-line logic creates fragile systems with hidden security holes and phantom libraries.

### 2. The Specification Prompt Pattern for Code
Vague coding prompts produce generic, bug-ridden code. High-precision software prompts specify:
1. **Context & Role:** `You are an expert Python systems engineer.`
2. **Contract Signature:** Exact function name, input types, and return type hint.
3. **Formal Invariants / Constraints:** Time complexity ($O(N)$), space limits, permitted vs forbidden libraries.
4. **Concrete Examples & Edge Cases:** How the function must behave on empty lists, negative inputs, and duplicates.

### 3. Critical Dangers of AI-Synthesized Code
* **Hallucinated Packages:** Recommending `import fast_greenhouse_ai` that does not exist in PyPI, opening users to 'Package Squatting' cyberattacks.
* **Security Vulnerabilities:** Hardcoding plain-text passwords, SQL Injection vulnerabilities, and missing input bounds.


## 5. Guided Demonstration & Mathematical / Computational Walkthrough
### Worked Prompt Transformation: Specification Pattern
* **Weak Prompt:** *'Write Python code to find temperature spikes.'*
* **Rigorous Specification Prompt:**
  ```text
  Write a Python function `detect_thermal_spikes(readings: list[float], window_size: int = 3, threshold: float = 5.0) -> list[int]`.
  - Input: Sequential list of ambient temperature floats.
  - Objective: Return indices where the temperature increases by more than `threshold` degrees compared to the moving average of the preceding `window_size` samples.
  - Constraints: Use only Python standard library. Time complexity must be O(N).
  - Edge Cases: Return [] if len(readings) <= window_size. Handle negative numbers gracefully.
  ```
The AI output will be immediately testable and production-ready.

## 7. Practical Hands-On Coding Lab
### Lab Assignment: Pair-Programming: Building and Testing a Moving Average Anomaly Detector
Write a clean, type-hinted Python function that calculates rolling window averages and flags anomalous spikes, accompanied by automated assertion unit tests.

```python
def detect_thermal_spikes(readings, window_size=3, threshold=5.0):
    """
    Detects indices where readings spike significantly above the rolling baseline.
    Parameters:
        readings (list[float]): Sequential sensor values.
        window_size (int): Number of prior samples for rolling average.
        threshold (float): Minimum spike delta to trigger flag.
    Returns:
        list[dict]: List of flagged anomaly records.
    """
    if not isinstance(readings, list) or len(readings) <= window_size:
        return []
        
    spikes = []
    
    for i in range(window_size, len(readings)):
        window = readings[i - window_size : i]
        rolling_avg = sum(window) / float(window_size)
        current_val = readings[i]
        delta = current_val - rolling_avg
        
        if delta >= threshold:
            spikes.append({
                "index": i,
                "value": current_val,
                "baseline": round(rolling_avg, 2),
                "spike_delta": round(delta, 2)
            })
            
    return spikes

# Automated Unit Tests
test_data = [20.0, 20.5, 21.0, 20.8, 32.5, 21.2, 21.0] # Clear spike at index 4 (32.5C)
flagged = detect_thermal_spikes(test_data, window_size=3, threshold=5.0)

print("=== AI-ASSISTED CODE EXECUTION REPORT ===")
print(f"Total Readings Inspected: {len(test_data)}")
print(f"Spikes Detected         : {len(flagged)}\n")
for f in flagged:
    print(f"Index {f['index']}: Value={f['value']}C (Baseline={f['baseline']}C, Delta=+{f['spike_delta']}C)")

# Assertion verification
assert len(flagged) == 1, "Test Failed: Expected exactly 1 spike."
assert flagged[0]["index"] == 4, "Test Failed: Spike should be at index 4."
print("\n[TEST SUITE PASSED]: All assertions verified successfully.")
```

## 9. Answer Keys & In-Depth Technical Solutions
### Question 1 Solution Breakdown
- **Correct Answer:** Option **B**
- **Detailed Explanation & Error Analysis:** Package hallucination occurs when an AI invents a plausible library name; attackers exploit this by uploading malware under that exact name to PyPI or npm.

### Question 2 Solution Breakdown
- **Correct Answer:** Option **B**
- **Detailed Explanation & Error Analysis:** Vague prompts leave crucial engineering decisions to chance, often resulting in suboptimal quadratic algorithms or missing edge-case handling.

### Question 3 Solution Breakdown
- **Correct Answer:** Option **B**
- **Detailed Explanation & Error Analysis:** Catch-all silent exception handling swallows bugs, making diagnosis and debugging almost impossible.

### Question 4 Solution Breakdown
- **Correct Answer:** Option **B**
- **Detailed Explanation & Error Analysis:** Responsible engineering treats AI as an acceleration co-pilot while retaining human accountability, line-by-line verification, and rigorous testing.
